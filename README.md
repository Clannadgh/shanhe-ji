# 山河纪 · 一个种子，一个世界，一百年

浏览器里跑的程序化世界生成器 + 回合制大战略沙盒。**零依赖、零构建**：
双击 `index.html` 就能玩（`file://` 直接运行，不用起服务器）。

> 选一个种子，生成一个世界；选一个国家，活过一百年；最后得到一本只属于你的编年史。

## 现在能玩到什么

| 层 | 内容 |
|---|---|
| **世界生成** | 种子 → 2400×1200 地图 / 约 1100 省 / 64 国；每省有地形、人口、七种资源储量、信仰；同种子逐字节可复现 |
| **视图** | 政治 / 地形 / 宗教 / 资源 / 迷雾五种，外加小地图、省份卡、国家卡 |
| **资源层** | 铁·金·粮·畜·木·鱼·盐七种资源；中央国库 vs 省库两本账；维护费与停产、货运与调拨损耗、粮仓 / 大学 / 工厂 |
| **治理层** | 三档税率、民心（逐项 drivers 可查）、人口税、开科取士（词条抽卡）、派官与撤换、俸禄 |
| **科研层** | 11 条科技（含军械枝）、科研点 / 人才点两条线、队列与冲刺 |
| **战争层** | 征兵、军械坊订单、行军与会战、围城、攻城、占领、投降并入、将领词条 |
| **事件与信仰** | 随机事件（自动选结果或玩家处置）、传教、国教 |
| **战争迷雾** | 情报署预算三档（兼反谍）、定向探测、关系值、AI 密探 |
| **编年史** | 每回合归档、年终年表、统一 / 灭亡定稿与称号 |
| **敌国内政 AI** | 敌国会自己盖房、研科技、调税、开科派官；三性格（经营 / 均衡 / 军国）走不同的优先级；会互相宣战、进攻、求和、灭国；官员会升迁、积怨、被赏被换；一打仗钱袋子自动换挡 |

## 怎么跑

双击 `index.html`。没有 `npm install`，没有打包步骤，也没有外部网络请求
（图标全是本地 PNG / 内联 SVG）。

- 面板左上「种子」+ 三个滑杆（省份 / 国家 / 陆地占比）→ **生成新世界**
- 右上「开始游戏」→ 选一个国家 → 之后每回合点「下一回合」
- 存档 / 读档走 `localStorage`：`file://` 下有些浏览器会禁用它，面板上会置灰并说明

## 状态

半成品但可玩：世界生成 → 选国 → 回合推进 → 资源 / 治理 / 科研 / 战争 / 事件 / 迷雾 / 编年史
整条链路都通。敌国 AI 的三条约束（不动经济 / 不主动进攻 / 敌国之间不打）已经全开，
外加吏部（赏赐 · 撤换）与战时经济换挡 —— 你挂机，世界自己会动。

纯前端、无后端、无遥测、不联网。所有数值都是占位，改平衡只需动
`js/15-resources.js` 的定义区。
