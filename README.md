# 山河纪 · 一个种子，一个世界，一百年

浏览器里跑的程序化世界生成器 + 回合制大战略沙盒。**零依赖、零构建**：
双击 `index.html` 就能玩（`file://` 直接运行，不用起服务器）。

> 选一个种子，生成一个世界；选一个国家，活过一百年；最后得到一本只属于你的编年史。

| **宰相（内阁）** | 玩家自己的"AI 政府"：开科有 3.8% 概率抽到宰相之才，拜相后每回合代劳你还没做的事。四级（守成 / 干练 / 贤相 / 权臣）各有权限与代价，头衔随政体 |

## 怎么跑

双击 `index.html`。没有 `npm install`，没有打包步骤，也没有外部网络请求
（图标全是本地 PNG / 内联 SVG）。

- 面板左上「种子」+ 三个滑杆（省份 / 国家 / 陆地占比）→ **生成新世界**
- 右上「开始游戏」→ 选一个国家 → 之后每回合点「下一回合」
- 存档 / 读档走 `localStorage`：`file://` 下有些浏览器会禁用它，面板上会置灰并说明

## 状态

半成品但可玩：世界生成 → 选国 → 回合推进 → 资源 / 治理 / 科研 / 战争 / 事件 / 迷雾 / 编年史
整条链路都通。敌国 AI 的三条约束（不动经济 / 不主动进攻 / 敌国之间不打）已经全开，
外加吏部（赏赐 · 撤换）与战时经济换挡 —— 你挂机，世界自己会动。
战争结局也不再只有"灭国"一种：可以把打崩的对手收成朝贡国（收租、征调、锁外交），
也可以被 AI 反过来要求称臣，然后等一个揭竿而起的机会。

纯前端、无后端、无遥测、不联网。所有数值都是占位，改平衡只需动
`js/15-resources.js` 的定义区。
